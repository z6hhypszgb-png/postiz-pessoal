Política de Privacidade

Aplicativo OAuth “Postiz” — integração pessoal de publicação · Última atualização: 22 de outubro de 2026

1. Quem é o responsável

O responsável é João Gabriel Gomes, pessoa física, titular do canal do YouTube João Gabriel Gomes | Alta Perfumaria (@joaogabrielgomes). Contato: joaogabriel.gs@hotmail.com.

2. O que é esta integração

É uma instalação pessoal e autohospedada do software livre Postiz, executada no computador do titular. Ela é usada somente por ele, para agendar e publicar vídeos no próprio canal. Não é um serviço oferecido ao público: o cadastro de novos usuários está desativado e o painel não é acessível pela internet. Por isso, os únicos dados tratados são os do próprio titular; esta integração não coleta dados de visitantes, espectadores ou outros usuários do YouTube.

3. Permissões solicitadas ao Google

O Postiz pede o conjunto de permissões abaixo de uma só vez; não é possível aprová-las em parte por ele. O titular concede a autorização pela tela de consentimento do Google e pode revogá-la quando quiser.

PermissãoO que permite, em termos gerais
youtube.uploadEnviar vídeos para o canal. É a permissão central para o uso pretendido.
youtube e youtube.force-sslGerenciar a conta do YouTube e o conteúdo do canal, o que inclui, tecnicamente, editar e excluir vídeos e comentários.
youtube.readonlyVer informações da conta e do canal.
youtubepartnerVer e gerenciar ativos e conteúdo associados no YouTube.
yt-analytics.readonlyVer relatórios do YouTube Analytics do canal.
userinfo.profile, userinfo.email, openidIdentificar a conta Google que autorizou.

Uso pretendido: o titular usa a integração para enviar e agendar vídeos, definir título, descrição, tags e privacidade, e acompanhar o estado das publicações. Algumas permissões acima são mais amplas do que esse uso, porque o Postiz as exige em conjunto; o titular não pretende usá-las para excluir ou editar conteúdo existente, mas tecnicamente o software as recebe.

4. Quais dados são tratados

  • Credenciais de autorização OAuth (token de acesso e token de renovação) da conta Google do titular.
  • Dados do canal: identificador, nome, nome de usuário (@) e imagem de perfil.
  • Conteúdo a publicar: arquivos de vídeo, título, descrição, tags, configuração de privacidade, data e horário do agendamento e o resultado de cada publicação.
  • Dados de acesso ao painel: e-mail e senha da conta administrativa local do Postiz (a senha é guardada pelo software em formato protegido).
  • Registros técnicos de funcionamento do software, mantidos localmente.

A integração não cria perfis de público, não coleta dados de espectadores e não usa dados sensíveis de outras pessoas.

5. Onde os dados ficam

Os dados ficam no computador do titular, no banco de dados e nos volumes do Postiz executados em contêineres Docker, e em cópias de segurança locais. Não afirmo criptografia dos tokens no banco além da proteção oferecida pelo próprio software e pelo sistema do computador (por exemplo, a proteção do disco e da conta de usuário).

Previsto, ainda não ativo: o titular pretende usar o armazenamento Cloudflare R2 para guardar os vídeos antes da publicação. Quando isso ocorrer, os arquivos de vídeo agendados ficarão armazenados na Cloudflare e acessíveis por um endereço público, e esta política será atualizada.

6. Com quem os dados são compartilhados

  • Google/YouTube: os vídeos e metadados são enviados à API do YouTube para realizar a publicação autorizada pelo titular.
  • Os dados não são vendidos, não são usados para publicidade e não são transferidos a terceiros, exceto o necessário para operar o serviço descrito acima (Google/YouTube e, quando ativado, a Cloudflare para armazenamento) ou se a lei exigir.
  • Nenhuma ferramenta de análise, publicidade ou rastreamento foi configurada nesta instalação.

7. Declaração de uso limitado (Google API Services)

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados obtidos por meio dessas APIs são usados apenas para fornecer e melhorar a funcionalidade descrita nesta página (publicar e acompanhar vídeos do canal do titular), não são usados para treinar modelos de inteligência artificial generalizados e não são lidos por pessoas, salvo com consentimento do titular, para segurança, para cumprir a lei ou quando agregados e anonimizados.

O uso dos serviços de API do YouTube está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

8. Retenção, revogação e exclusão

  • Os tokens e os dados do canal permanecem enquanto o canal estiver conectado ao Postiz.
  • Revogar o acesso: em myaccount.google.com/permissions, o titular remove o acesso do aplicativo “Postiz” à conta Google a qualquer momento.
  • Desconectar: remover o canal no painel do Postiz encerra o uso. O software pode manter, no banco de dados, o registro da integração marcado como excluído.
  • Exclusão completa: o titular apaga os volumes e as cópias de segurança do Postiz no próprio computador, o que elimina os dados locais.
  • Vídeos já publicados no YouTube seguem as regras do YouTube e podem ser removidos pelo titular no YouTube Studio.

9. Segurança

O painel e os serviços de apoio do Postiz escutam apenas no endereço local do computador e não são expostos à internet; o cadastro de novos usuários está desativado e as senhas internas são geradas de forma aleatória. Isso reduz riscos, mas nenhum sistema é totalmente imune a falhas, e não há garantia de segurança absoluta.

10. Crianças

A integração não é direcionada a crianças e não trata dados de crianças.

11. Este site

Este site é estático e hospedado no GitHub Pages. Não usa cookies nem ferramentas de análise. O GitHub, como provedor da hospedagem, pode registrar dados técnicos de acesso (como endereço IP) conforme a Declaração de Privacidade do GitHub.

12. Alterações

Esta política pode ser atualizada, por exemplo quando o armazenamento em nuvem for ativado ou quando novas plataformas forem conectadas. A data de atualização fica no topo da página.
